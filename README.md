# 🎮 High Tech PS - PlayStation Maintenance & Jailbreak Center

مرحباً بك في المستودع الرسمي لـ **High Tech PS**. يوفر هذا المشروع الواجهة والملفات الخاصة بمركز صيانة وتعديل أجهزة البلايستيشن (PS4 & PS5)، مع تفعيل التعديلات والبايلود بنقرة زر واحدة.

---

## 🚀 المميزات الرئيسية (Features)

- **تفعيل التعديل بضغطة زر (One-Click Jailbreak Activation):** تشغيل سريع للتعديلات والبايلودز لأجهزة PS4 و PS5.
- **دعم إصدارات PS4:** دعم كامل لإصدارات النظام (9.00 / 11.00 وجميع الإصدارات المدعومة).
- **دعم إصدارات PS5:** تفعيل الثغرات الخاصة بالنظام لجميع الإصدارات المتاحة.
- **صيانة الدعم الفني:** قسم للتعريف بالخدمات والأعطال التي يتم إصلاحها في المركز.
- **عمل بدون إنترنت (Offline Cache):** إمكانية حفظ المتصفح للبيانات لتشغيل التعديل بدون الحاجة لاتصال بالإنترنت بعد أول زيارة.
